# AI Trading Intelligence System (ATIS)

نظام تداول خوارزمي ذكي معياري — من جلب بيانات MT5 إلى التنفيذ الحي (Paper/Demo).

## الحالة الحالية

- [x] المرحلة 1: البنية التحتية المشتركة
- [x] المحرك 1: جلب البيانات (تفاضلي + backfill)
- [x] المحرك 2: تنظيف البيانات
- [x] المحرك 3: المؤشرات والأنماط (`shared/feature_engine`)
- [x] توسيع 1–3 لكل الرموز والأطر (حدود تاريخ الوسيط على M1/M5)
- [x] المحرك 4: تدريب Walk-Forward + backtest بتكاليف
- [x] المحرك 5: Paper/Demo (إدارة مخاطر إلزامية، بدون live حقيقي)
- [x] التركيز على **الذهب XAUUSD** في التداول الحي
- [x] واجهة ويب Gold Desk مربوطة بكل المحركات

## إعداد سريع

```bash
pip install -e ".[dev]"
# بيانات MT5 في config/secrets.env (لا تُرفع إلى git)
python -m atis.scripts.ping_mt5
```

## تشغيل الواجهة

```bash
python -m atis.web.run
# افتح http://127.0.0.1:8787
```

الواجهة مربوطة بكل نقطة: MT5، Registry، المحركات 1–5، التقارير، النماذج، الصفقات، وإيقاف الطوارئ.
التداول الحي مقصور على **الذهب XAUUSD**.

## ملاحظات مهمة

- رموز Windsor Demo تستخدم لاحقة `@` (مثل `EURUSD@`) — تُحل تلقائياً.
- عمق التاريخ يعتمد على الوسيط (غالباً أقل من 3 سنوات على M1).
- الوضع `live` برأس مال حقيقي **مرفوض** حتى موافقة صريحة منك.
- النظام أداة احتمالية وليس ضمان ربح.
